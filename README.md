# TommyLiveTV APK Downloads

This repository distributes the TommyLiveTV Android phone app APKs. Source code is not hosted here.

Download the current build from the [Releases](https://github.com/jackreacherdota/TommyLiveTV-Downloads/releases) page. The current test build is debug-signed and ARM64-only.

When switching from a debug-signed APK to a release-signed APK, Android may require uninstalling the debug build first. Uninstalling removes app-local data, including downloaded videos.
